---
title: Share links
icon: LuShare2
description: Copy a link to any page or folder and send it to a teammate.
---

GitQuire has a **Share** button on the right of the header, or in its
[**More actions**](/docs/features/editor#when-the-header-runs-out-of-room) menu when the header is
full. Click it and GitQuire copies a link to the current page or folder on your GitQuire server,
for example `https://wiki.example.com/#/project-atlas/kick-off-meeting`.

Everyone works on the same server, so the link opens the same page for anyone who can sign in. A
folder link opens the folder's overview.

## When the link can't be copied

If the browser doesn't allow copying, the Share popover shows the link selected, so you can copy it
with **⌘ C** (macOS) or **Ctrl C** (Windows, Linux).

## Who can open it

The link needs a GitQuire account: anyone who opens it signs in with GitHub first and must be
allowed on the server. See [GitHub sign-in](/docs/gitquire/github-sign-in).

A link opens the page on the live wiki. To share a page in a draft, add the draft to the link
(`/?draft=<name>#/page`); see [Drafts](/docs/gitquire/drafts).
