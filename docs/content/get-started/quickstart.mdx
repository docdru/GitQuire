<Steps>

<Step>

### Start the server

GitQuire ships as one Docker image. On a machine with Docker:

```bash
docker run --rm -p 8080:8080 \
  -e OK_ALLOW_EXTERNAL=1 \
  -v gitquire-data:/data \
  ghcr.io/docdru/gitquire:latest
```

Then open `http://localhost:8080`. To run it behind your own domain, see
[Run with Docker](../gitquire/run-with-docker.mdx).

</Step>

<Step>

### Turn on GitHub sign-in

Before anyone else can reach the server, [turn on GitHub sign-in](../gitquire/github-sign-in.mdx).
Everyone then signs in with their GitHub account, and edits are committed under their name.

</Step>

<Step>

### Connect a repository

[Sync a GitHub repository](../gitquire/repository-sync.mdx) so every page is saved as a Markdown
file in Git and pushed automatically.

</Step>

<Step>

### Create your first page

Right-click in the sidebar (empty space or a folder) and create a document. Type a title and start
writing: the editor is WYSIWYG, with a source-mode toggle for plain Markdown. Type `[[` to link
another page.

When viewing a document, the right side pane shows:
- An outline of the document's structure
- Incoming and outgoing links, including [typed links](../gitquire/typed-links.mdx)
- A graph view of the document's links
- A [timeline](/docs/features/timeline-and-recovery) of recent edits with diffs and selective rollback

Select text to start a [comment thread](../gitquire/comments.mdx), and `@mention` a teammate to
notify them. The full feature tour is under [Features](/docs/features/editor).

</Step>

<Step>

### Connect an AI agent

Agents such as Claude can read and edit the wiki over MCP. See
[Connecting agents](../remote-control/connecting-agents.mdx).

</Step>

</Steps>
