title: What is GitQuire?
icon: LuBookOpen
description: A self-hosted, collaborative WYSIWYG Markdown editor for small teams, with every page, link and comment stored in Git.
---

GitQuire lets a small team write together in a Notion-like editor while every page stays a plain
Markdown file in a GitHub repository.

- **Write together.** Live cursors for meetings, and automatic commits for async work.
- **Plain Markdown in Git.** Every page is a `.md` file; edits are committed and pushed after a
  short pause, under the author's own GitHub name.
- **Branches and pull requests.** Propose a bigger change on a branch and open a pull request from
  the editor.
- **Links that stay correct.** `[[wiki links]]`, backlinks, link-friendly file names, and links
  rewritten when a page is renamed or moved.
- **Typed links.** Optionally say how pages relate, such as `supersedes:: [[Decision 9]]`, and see
  the relation in links, backlinks and the graph. See [typed links](./typed-links.mdx).
- **Discussions in the file.** Comment threads with replies and @mentions live in a hidden block at
  the end of each page, so they travel through Git like everything else.
- **Mentions that reach people.** A mention inbox in the app, and optionally email or a post in
  your team chat. See [mentions and notifications](./mentions.mdx).
- **Pages as objects.** Give pages properties and see them as a table, a board, or one list of all
  action items. See [views](./views.mdx).
- **Works on phones.** Install it to the home screen and edit with a toolbar above the keyboard.
- **Self-hosted.** One Docker container, one volume, GitHub sign-in.
