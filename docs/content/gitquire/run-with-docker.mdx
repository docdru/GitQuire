---
title: Run with Docker
icon: LuContainer
description: Start the GitQuire container, keep its data in a volume, and put it behind your domain.
---

```bash
docker run --rm -p 8080:8080 \
  -e OK_ALLOW_EXTERNAL=1 \
  -v gitquire-data:/data \
  ghcr.io/docdru/gitquire:latest
```

Then open `http://localhost:8080`.

<Callout type="warn">
  Without [GitHub sign-in](./github-sign-in.mdx), anyone who can reach the port can read and edit
  everything. Turn sign-in on before exposing GitQuire beyond your own machine.
</Callout>

## Behind a domain

Put GitQuire behind a reverse proxy that terminates HTTPS and forwards WebSocket upgrades, and set
`OK_EXTERNAL_URL` to the public origin, for example `https://brain.example.com`.

Run exactly **one container per volume**: the collaboration server is the single writer of the
working copy. Health checks are `GET /healthz` (process up) and `GET /readyz` (ready to serve).

## Settings

| Variable | Default | Meaning |
| --- | --- | --- |
| `PORT` | `8080` | Listen port |
| `OK_BIND` | `0.0.0.0` | Bind address |
| `OK_ALLOW_EXTERNAL` | unset | Must be `1` to accept connections from other machines |
| `OK_EXTERNAL_URL` | unset | Public origin; required behind a domain or proxy |
| `GITQUIRE_GIT_NAME`, `GITQUIRE_GIT_EMAIL` | `GitQuire`, `gitquire@localhost` | Fallback Git identity for commits nobody signed in made |
| `GITQUIRE_NAMING` | `slug` | `off` keeps new page names exactly as typed ([page names](./page-names.mdx)) |
| `GITQUIRE_SMTP_URL`, `GITQUIRE_MAIL_FROM` | unset | Mail server and sender for mention email ([mentions](./mentions.mdx#set-up-email)) |
| `GITQUIRE_MAIL_DOMAINS` | unset | Optional domains people may enter for mention email |
| `GITQUIRE_CHAT_WEBHOOK_URL` | unset | Post new mentions to a team chat ([mentions](./mentions.mdx#team-chat)) |

The image is published from `main` as `ghcr.io/docdru/gitquire:latest` and
`ghcr.io/docdru/gitquire:sha-<commit>`. Pin a `sha-` tag in production.
