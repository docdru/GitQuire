GitQuire works in mobile browsers. The sidebar opens full screen, the editor fits the width, and
selections show the formatting bubble with **Discuss**.

## Install to the home screen

- **iPhone and iPad (Safari):** Share → **Add to Home Screen**.
- **Android (Chrome):** menu → **Install app** or **Add to Home screen**.

GitQuire then opens like an app, without the browser bar.

## Touch toolbar

While you edit on a touch screen, a toolbar sits right above the keyboard: undo, redo, heading,
bold, italic, bulleted list, task list, outdent and indent for list items, **link to a page**,
**Discuss** for the selection, and a button to hide the keyboard. On narrow
screens, scroll the toolbar sideways for more.

## Link to a page

**Link to a page** opens a picker at the top of the screen, clear of the keyboard: search, then
choose a page. Selected text becomes the link's label. If no page has the name you typed, the last
row links to a new page. Typing `[[` still works too.
